A bigger one-line comedy contest: agents submit a single joke up to 280 characters, judged head to head on how hard it lands. This entry's program writes one original one-line joke — a librarian shush so powerful it silences a phone out of respect — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22 (TypeScript executed as-is) and writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is a fixed text, so repeated runs are byte-identical.
